1. 슬롯 이름 계약 — 유지, 배치만 세로 보드

플랜 §5 가 확정한 슬롯 이름은 그대로다(다른 플랜 3개가 이 이름으로 자기 줄을 끼운다). 바뀌는 것은 배치뿐 — 평문 한 줄들이 구분선으로 묶인 블록이 되고, 재화 한 줄이 4행으로 펼쳐진다.

보드 구역슬롯(생성 순서)소유 플랜비고
① 머리Title · Best이 플랜(T2)Best 가 줄 → 제목 우측 배지로. 갱신 시에만 활성
② 기록Clears → Delta → Fever → Goal이 플랜(T1·T2) / P3 · P4클리어는 큰 숫자 + 카운트업 0.75s, 나머지는 아래 캡션 줄. Fever(P3)·Goal(P4)는 이 구역 안에 들어간다 — 이 플랜은 자리만 예약(줄 생성 0)
③ 재화Gold · Currency · Wallet이 플랜(T1)1줄 → 4행. Wallet 은 각 행 우측 흐린 값으로 흡수
④ 행동Tickets → Pin → NextAction이 플랜(T3·T4) / P6각 행에 mini 버튼 1개. _focusOrder 에는 넣지 않는다. Pin 은 P6 가 이 구역 안에 끼운다
⑤ 버튼Buttons이 플랜(T5)포커스 0번 = 다시 시작, 라벨 골드
