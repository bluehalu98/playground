UI 아이콘 시트 — 이모지 대체 9칸

출처: owner 2026-09-03 결정 ㄴ(우리 스프라이트) · 플랜 emoji-asset-path-plan.md

폰트에 글리프가 없어 Renderable() 가 지우거나 두부 □ 로 나오는 자리를 스프라이트로 덮는다. 기준 문법은 기존 UI/Progression/** 19장 — 512×512, 흰 단색 실루엣, 외곽선 없음, 투명 배경. 런타임에서 Image.color 로 틴트하므로 반드시 흰색 단색이어야 한다. 산출물은 Assets/Resources/UI/Progression/Icons/<name>.png, 캡처는 npm run capture:ui-icons.

A. 기준 — 기존 에셋 (참조용, 손대지 않는다)

이 19장이 톤의 정본이다. 신규 9칸은 이 두께·여백·둥근 정도를 따른다.

B. 신규 9칸

3칸(🏆 crown · 🔒 padlock-locked · 🎲 chest)은 기존 에셋으로 덮으므로 여기 없다 — 두부 □ 16곳은 그 두 장(crown·padlock)으로 닫힌다.

C. 실사용 크기 판독

게임에서 실제로 나오는 크기다. 16~24px 에서 형태가 뭉개지지 않는지가 합격 기준.

D. 호버 프레임 (2026-09-05 · ② 스왑 · ③ 스트립)

왼쪽부터 f0(기본) → f1…f5. f0 은 기본 아이콘 자신이라 png 를 따로 만들지 않는다. 오른쪽 칸은 게임과 같은 12fps 로 돌린다 — 정지 그림으로는 판정이 안 되는 물건이라 여기서 눈으로 본다. 색은 프레임 사이에 바뀌지 않는다(런타임 틴트가 정본).
