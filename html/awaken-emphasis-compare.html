각성 강조 띠 — 축별 아웃셋 비교 (최소 줌 0.35 · 코드 실측 좌표 · 확대 ×12)

카드 공간에 준 등방 3px 아웃셋이 시트 실루엣 비율(68/128 × 102/128, T1 실측)에 곱해지면서 화면에서는 가로 2.00px · 세로 3.00px 로 갈린다. 세로는 자기 카드를 넘어 이웃 몸통 사이의 빈틈(1.9395px · 초록 빗금)을 1.06px 침범한다. ⚠ owner 판정용 아티팩트가 제시한 “가로를 키운다”는 방향이 반대였다 — 균일화는 세로를 줄이는 쪽이다.

현행 아웃셋 (3, 3)

띠 가로2.0000 px
띠 세로3.0000 px
세로 이웃 침범1.0605 px

띠가 가로 2.00 / 세로 3.00 으로 갈린다. 세로 강조가 이웃 몸통을 1.06px 파고든다 — 초록 빗금(카드 간 빈틈 1.9395px)을 넘어선 부분이 그것이다.

ⓐ 세로를 가로에 (채택) 아웃셋 (3, 2)

띠 가로2.0000 px
띠 세로2.0000 px
세로 이웃 침범0.0605 px

가로는 건드리지 않는다(픽셀 무변경). 세로만 3.0 → 2.0. 침범이 0.06px 로 사실상 사라진다. 대신 띠가 세로로 1px 얇아 보인다.

ⓑ 가로를 세로에 아웃셋 (4.5, 3)

띠 가로3.0000 px
띠 세로3.0000 px
세로 이웃 침범1.0605 px

띠를 3.00 으로 키운다 — 지금의 세로 두께가 유지되고 가로가 굵어진다. 다만 세로 침범 1.06px 는 그대로 남는다. 폐기된 ⓒ 도 계산하면 이 값과 완전히 동일하다.

1:1 대조 확대 없음 — 실제 최소 줌에서 이만하다

왼쪽부터 현행 / ⓐ / ⓑ. 이 크기에서 ⓐ 와 현행의 차이는 세로 1px 이고, ⓐ 와 ⓐ′(침범 정확히 0)의 차이 0.06px 는 여기서 보이지 않는다 — 그래서 ⓐ′ 는 owner 판정 항목으로 올리지 않았다.
