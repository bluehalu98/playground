현재 이 게임에 방향키 조작은 없다. 키보드 입력 전체가 Escape(일시정지)와 Space(버프 방출) 둘뿐이고, 둘 다 런 전용이다 — 즉 메뉴 화면은 키보드가 완전히 비어 있어 방향키를 넣어도 충돌할 게 없다.

직접 눌러 보세요 — 아래 스테이지를 클릭해 포커스를 준 뒤 ↑ ↓ 로 이동, Enter 로 실행. 세 안이 동시에 움직이므로 나란히 비교됩니다. 마우스를 올리면 hover는 따로 뜬다 — hover와 포커스는 다른 상태라는 것도 같이 봐 주세요.

6-b. 그런데 메뉴만 있는 게 아니다 — 격자에서는?

젬 인벤토리(UI.cs:3493)와 합성 후보칩(:4098)은 폭에 따라 열 수가 계산되는 2D 격자다. 장비 보드도 마찬가지다. 지금은 v1 범위 밖이지만 여기서 쓸 수 없는 표현을 v1에서 확정하면 나중에 두 번 정하게 된다. ← → ↑ ↓ 로 움직여 보세요.

B안(좌측 바)을 격자에 그대로

리스트 관용구
좌측 바는 "세로로 흐르는 목록"이라는 뜻이다. 격자에서는 방향이 안 읽힌다 — 좌우로 움직였는데 표시는 계속 왼쪽에만 붙는다.

A안(외곽 링)을 격자에

전방향 관용구
링은 전방향이라 상하좌우 어디로 움직여도 같은 의미로 읽힌다. 격자에는 이쪽이 맞다.
그래서 제안 — 하나를 고르는 게 아니라 규칙을 고르는 것이 맞아 보인다. "포커스 = teal"을 규칙으로 두고, 형태는 위젯을 따라간다: 리스트 행 → B(좌측 바) · 격자 카드 → A(링). §0을 색 6개가 아니라 언어 4개로 정의한 것과 같은 방식이다. C(캐럿)는 단독 지표로 쓰기엔 약하지만 리스트에서 B와 겹쳐 쓰면 게임 정체성이 살아난다.

✓ 2026-08-08 owner 승인 — 이 규칙으로 확정. 이후 새 위젯이 생기면 "포커스 = teal"만 지키고 형태는 그 위젯의 관용구를 따른다.
왜 포커스 색이 문제인가 — 컨셉 규칙(§0-C)상 teal = 활성, 금 = 강조·수치다. 그런데 V2에서 주 버튼이 금색이라, 포커스도 색으로 표현하면 한 버튼에 금과 teal이 겹친다. A안이 그 충돌을 정면으로 맞고, B/C안은 색이 아닌 다른 축(좌측 바 / 캐럿)으로 피한다.
